# Measuring demand for clinic credential tracking

The original inventory contains 15 candidate pages. No keyword-volume, search difficulty, impression or conversion dataset accompanies it. Page order is editorial. An experiment with no paid media still incurs writing, review and support costs.

## First experiment

Publish a dental spreadsheet page and a dental product page. Explain the proposed $39/month offer and 14-day trial only when a visitor can actually take the described action. Use the example CSV to demonstrate import. Its alert dates and status are fixed examples. Editing the expiration date in a CSV does not recalculate them. Enter issuers and dates from practice records.

Use Search Console to record impressions, clicks, click-through rate and query by landing page and week. Record eligible visits, downloads, trials, first completed roster imports, first paid clinics and refunds. Attribute each clinic once per acquisition cohort. Keep community referrals separate from organic search. Measure:

- Search click-through rate = clicks / impressions from the same Search Console slice.
- Visit-to-trial rate = new attributed trials / eligible landing visits.
- Activation rate = trial clinics completing a roster import / trial clinics.
- Trial-to-paid rate = clinics making a first successful payment / trials with a completed observation window. Record the cutoff and count trials still open separately.
- Acquisition cost = (paid spend + attributed outreach and editorial labor cost) / newly paying clinics.

Report raw counts, cohort dates and denominators. A zero denominator yields no rate. Compare the workflow page with the template page on paid clinics and support effort. Use the results to decide which additional topics merit publishing. A sitemap can help discovery. Google provides no guarantee of indexing, rank or timing. [Google Search Central](https://developers.google.com/search/help/crawling-index-faq)
